
# GrahakNyay Prompt Comparison

## Objective
Compare two prompt versions using 10 consumer questions.

## Prompt Version 1
A basic prompt that asks the AI to answer consumer questions using the available legal records.

## Prompt Version 2
The improved GrahakNyay system prompt that:
- Uses supplied legal records as the primary source.
- Does not invent legal sections, fees, or procedures.
- Identifies missing information.
- Uses simple English.
- Returns JSON with answer, confidence, and follow_up.

## Test Questions

1. What are my consumer rights in India?
2. I purchased a defective laptop online. What can I do?
3. What is a deficiency in service?
4. What is an unfair trade practice?
5. How can I file a consumer complaint?
6. What is the right to be informed?
7. What is product liability?
8. Can I complain if an online seller refuses a refund?
9. What is consumer mediation?
10. How much time does a consumer commission take to decide a case?
